# TorqueController

トラックパッドだけでキーボード操作を完結させる、Mac専用のスクリーンキーボード。日本語のフリック入力と、同心円で候補を選ぶかな漢字変換を持つ。仕様は [DESIGN.md](DESIGN.md) を参照。

## ビルドと起動

初回だけ、ローカル署名用の証明書を作る。再ビルドしてもアクセシビリティの許可が外れないようにするためのもの。

```bash
scripts/create-signing-identity.sh
```

初回と、辞書を更新するときだけ、辞書データを取得してバイナリにする。元データは git に含めない。

```bash
scripts/fetch-dictionary.sh
```

```bash
scripts/build-dictionary.sh
```

ビルドして起動する。

```bash
scripts/build-app.sh
```

```bash
open .build/app/TorqueController.app
```

初回の起動時に、システム設定の「プライバシーとセキュリティ > アクセシビリティ」で TorqueController を許可する。

## 使い方

- **コンパクトパネル**: 常に表示する。Esc、修飾キー、十字キーと、QWERTYパネルとフリックパネルの切替キーがある。
- **フリックパネル**: 文字入力欄にフォーカスすると出る。キーを押してドラッグし、離した方向の文字を入力する。
- **変換**: 未確定のかながあるときに変換キーを押すと、候補が同心円で出る。クリックで選び、全て選ぶか送信キーで送る。
- **ショートカット**: 修飾キーをクリックして QWERTYパネルのキーを押すか、修飾キーからドラッグして同心円で選ぶ。設定はメニューから開いて編集する。
- **全パネルのオン/オフ**: 画面の右下の隅に 0.5 秒カーソルを置く。
- **移動と倍率**: 各パネルの六点の持ち手をドラッグして動かし、クリックで倍率を選ぶ。

その他の設定は、メニューバーのアイコンから変える。

## 変換エンジンの確認

読みを渡すと、列ごとの候補とスコアの内訳を表示する。辞書を作ったあとに使える。

```bash
.build/release/torque-cli こんばんには
```

## 使う権限

- アクセシビリティ: 対象アプリへキー入力を送る、フォーカスしている要素を調べる、Electron アプリに入力欄を出してもらう属性を設定する、ために使う。

## 止め方

通常はメニューバーのアイコンから「TorqueController を終了」を選ぶ。

メニューが使えないときは、ターミナルから止める。

```bash
pkill -x TorqueController
```

それでも止まらないときは、強制終了する。

```bash
pkill -9 -x TorqueController
```

修飾キーを押したままにする送り方はしないので、強制終了しても押下中の状態は残らない。
