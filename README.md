# TorqueController

トラックパッドだけでキーボード操作を完結させる、Mac専用のスクリーンキーボード。日本語のフリック入力と、同心円で候補を選ぶかな漢字変換を持つ。仕様は [DESIGN.md](DESIGN.md) を参照。

## ビルドと起動

初回だけ、ローカル署名用の証明書を作る。再ビルドしてもアクセシビリティの許可が外れないようにするためのもの。

```bash
scripts/create-signing-identity.sh
```

初回と、辞書を更新するときだけ、辞書データを取得してバイナリにする。元データは git に含めない。

```bash
scripts/fetch-dictionary.sh
```

```bash
scripts/build-dictionary.sh
```

ビルドして起動する。

```bash
scripts/build-app.sh
```

```bash
open .build/app/TorqueController.app
```

初回の起動時に、システム設定の「プライバシーとセキュリティ > アクセシビリティ」で TorqueController を許可する。

## 配布用の .dmg

知人に渡す .dmg を作る。ビルドと署名もこの中で行う。渡す前に、[App/Info.plist](App/Info.plist) の CFBundleVersion を上げる。

```bash
scripts/build-dmg.sh
```

`.build/TorqueController-0.1.dmg` ができる。中身は TorqueController.app、アプリケーションフォルダへのリンク、受け取った人向けの案内([App/ReadMe-ja.html](App/ReadMe-ja.html) から作る)。Apple シリコンの Mac と macOS 15 以降が必要。

アイコンの元データは [App/AppIcon.svg](App/AppIcon.svg) と [App/MenuBarIcon.svg](App/MenuBarIcon.svg) で、`scripts/build-icons.sh` が書き出す(build-app.sh から呼ぶ)。追加のインストールは要らない。

## 使い方

- **コンパクトパネル**: 常に表示する。Esc、修飾キー、十字キーと、QWERTYパネルとフリックパネルの切替キーがある。
- **フリックパネル**: 文字入力欄にフォーカスすると出る。キーを押してドラッグし、離した方向の文字を入力する。
- **変換**: 未確定のかながあるときに変換キーを押すと、候補が同心円で出る。クリックで選び、全て選ぶか送信キーで送る。
- **ショートカット**: 修飾キーをクリックして QWERTYパネルのキーを押すか、修飾キーからドラッグして同心円で選ぶ。設定はメニューから開いて編集する。
- **修飾キー付きのクリック**: コンパクトパネルの修飾キーを選んでから、画面のどこかをクリック、ドラッグ、スクロールすると、修飾キーを押しながらの操作として届く(例: ⇧ を選んでクリックすると ⇧+クリック)。使い終えると選択は外れる。固定した修飾キーは外すまで全ての操作に乗る。
- **全パネルのオン/オフ**: 画面の右下の隅に 0.5 秒カーソルを置く。
- **移動、不透明度、倍率**: 各パネルの六点の持ち手をドラッグして動かす。クリックすると、そのパネルの不透明度と倍率を選ぶメニューが開く。

その他の設定は、メニューバーのアイコンか、パネルの右クリックで開くメニューから変える。アクセシビリティが未許可の間は、メニューバーのアイコンが三角の警告の記号になる。

すでに動いているときにもう1つ起動すると、新しい方はパネルを出さずに終了する。

## 使う権限

- アクセシビリティ: 対象アプリへキー入力を送る、フォーカスしている要素を調べる、Electron アプリに入力欄を出してもらう属性を設定する、ために使う。

## 止め方

通常はメニューバーのアイコンから「TorqueController を終了」を選ぶ。どのパネルの右クリックで開くメニューからも、同じ項目で終了できる(ノッチの裏にアイコンが隠れているときなど)。

メニューが使えないときは、ターミナルから止める。

```bash
pkill -x TorqueController
```

それでも止まらないときは、強制終了する。

```bash
pkill -9 -x TorqueController
```

修飾キーは押して離すまでを一続きで送るので、操作と操作の間に押下中の状態は残らない。
